# Corridor design context

A light, compact truck route planning workspace with forest green navigation, warm neutral surfaces, DM Sans typography, and consistent weather-risk colors. The primary task is trip analysis; route comparison, map checkpoints, and forecast playback have distinct controls.

React + TypeScript + Leaflet, with custom CSS tokens in `frontend/src/styles.css`. Catalog search required unavailable authentication; the interface uses custom components. Preserve the explicit sample/live distinction, keyboard place selection, and separate arrival-time risk versus forecast slider behavior.
